# Django Сервис Управления Рассылками
## Описание проекта
Этот сервис позволяет пользователям управлять email-рассылками, создавая, редактируя и отслеживая их выполнение. Веб-приложение разработано на Django и поддерживает регистрацию пользователей, управление клиентами и сообщениями, а также сбор статистики о рассылках.

# Функционал
1. 👥 Управление клиентами
** Добавление, просмотр, редактирование и удаление получателей рассылки.**
**Поля модели клиента:**
 - Email (уникальный).
 - ФИО.
 - Комментарий.

2. Управление сообщениями
**CRUD-операции с сообщениями.**
** Поля модели сообщения:**
  - Тема письма.
  - Тело письма.
    
3. Управление рассылками
**CRUD-операции с рассылками.**
**Поля модели рассылки:**
  - Дата и время первой отправки.
  - Дата и время окончания.
  - Статус ("Создана", "Запущена", "Завершена").
  - Привязка к сообщению и получателям.
**Включена автоматическая отправка через Celery.**

4. Отправка сообщений
**Вручную через интерфейс.**
**Из командной строки (кастомной командой Django).**

5. Статистика
**Отчёты по успешным и неуспешным попыткам рассылок.**
**Количество активных рассылок и уникальных клиентов.**

6. Аутентификация и права доступа
**Регистрация и вход пользователей через email.**
**Разграничение ролей:**
  - Пользователь – управляет только своими данными.
  - Менеджер – может просматривать всех клиентов и рассылки, но не редактировать их.

7. ⚡ Кеширование
**Настроено серверное кеширование для ускорения работы.**

#🛠 Технологии
Backend: Python, Django, Celery, Redis
Database: PostgreSQL
Frontend: Django Templates, Bootstrap
